HueForge Web — архитектура

Изображение в браузере → многослойная филаментная модель (STL / 3MF) и локальный Node-сервер для передачи в слайсер

Вычисления на клиенте

  • • Всё считается в браузере — изображения не покидают ПК
  • • Тяжёлые шаги (квантование, меш) — в Web Worker с объединением запросов
  • • Viewer3D: отрисовка по необходимости, орбита и вид сверху
  • • 9 брендов филамента РФ + свои катушки

Локальный сервер с узкой задачей

  • • node:http на 127.0.0.1 — наружу не открыт
  • • Отдаёт готовый deploy-пакет (на целевом ПК не нужны сборщики)
  • • Единственный API с защитой: открыть экспорт в слайсере
  • • Поиск слайсера по типовым путям установки или по своему

Поставка и релизы

  • • CI на каждый push: typecheck + 292 теста Vitest + сборка
  • • Семантические теги создают релизы GitHub
  • • Артефакт релиза: hueforge-web-deploy-vX.Y.Z.zip (Node + deploy.bat)
  • • install.bat ставит dev-окружение; update.ps1 — обновления

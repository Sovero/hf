HueForge Web · процесс подготовки печати

От исходной картинки до готового STL / 3MF: тяжёлые вычисления уходят в Web Worker, а ручные решения остаются в UI.

Граница ответственности

  • • UI принимает решения и показывает живой статус.
  • • Pipeline Worker считает квантование и mesh.
  • • Reference Worker читает большой 3MF отдельно.

Что сохраняется

  • • Настройки, тема, язык и катушки — localStorage.
  • • τ сохраняется для точного предпросмотра.
  • • Проект можно упаковать в .hueforge.json.

Desktop delivery

  • • Electron даёт окно и native Save As.
  • • electron-updater проверяет GitHub Releases.
  • • Browser и desktop используют один pipeline.

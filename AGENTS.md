# Language

Общение и рассуждения — на русском во всех сессиях. Ответы,
комментарии в чате и внутренние размышления — всегда на русском.

# Autopilot

Сборка ведётся навыком `/autopilot`. Требования, спека и задачи — в `.autopilot/`.
Прогресс — `.autopilot/dashboard.html`. Правило: требование из `manifest.md`
может снять только пользователь.

# Skills sync

Локальные скиллы — резервная копия в `https://github.com/Sovero/skills.git`
(категории = направления). По запросу «сохрани/синхронизируй скиллы» (и после
установки/обновления скиллов) запускать
`powershell -File scripts/sync-skills.ps1 -Push` из клона репозитория скиллов;
скрипт сам читает `~/.claude/skills`, `~/.config/opencode/skills`,
`~/.agents/skills`, раскладывает по категориям, коммитит и пушит.

# Документация

Вся документация репозитория — `README.md`, `DEPLOY.md`, `CHANGELOG.md`,
`docs/` — ведётся на русском языке. Новые документы пишутся по-русски,
существующие правки переводятся. Без перевода остаются только команды,
имена файлов и путей, фрагменты кода и общепринятые термины (STL, 3MF, CI).
Русский текст README обязателен и должен быть виден на GitHub — страница
репозитория читается по `README.md` из ветки по умолчанию.

Описание репозитория на GitHub (About) и ноты релизов тоже ведутся по-русски.
Сообщения коммитов — conventional-commit с русским описанием после префикса:
они попадают в `CHANGELOG.md`, когда у релиза нет своих нот.

🎨 HueForge Web

Image → multi-layer 3D-printable filament painting

Welcome! Turn any picture into a multi-color 3D-printed painting: load an image, pick how many filament colors to use, and download the model with a color-swap guide. Work through the numbered sections top to bottom — the previews update live.

1 · Image

Start here. Drop in a photo or drawing — the app will reduce it to flat color bands for printing.

Drop an image here

or click to browse — PNG / JPG / WebP

2 · Colors

How many filament colors to print with. More colors = smoother shading, but more manual filament swaps.

Drag the slider, or type a count (2–24) in the box

3 · Depth mode

Which parts of the picture stand tallest: light areas or dark ones. This sets the print order of the colors.

4 · Size & layers

Physical print dimensions and layer settings. The resolution of the working image adapts to the print size automatically.

Colors are stacked as equal bands from base to max height.

5 · Printability check

Automatic check of your settings: band thickness, detail size vs nozzle, fragile specks, and the number of swaps. Fix anything marked with ⚠ or ✕.

Load an image to run the check.

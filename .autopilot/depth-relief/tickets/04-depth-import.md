# 04 — Импорт карты глубины PNG

**Требования:** U01
**Blocked by:** 01, 02
**Status:** ready

## Что должно заработать

Источник «Из файла»: пользователь загружает готовую карту глубины/высот (PNG 8 или 16 бит). Карта декодируется без потери 16-битной точности, приводится к `DepthMap` и масштабируется под картинку; дальше путь общий с нейросетью.

## Из брифа, дословно

> «https://github.com/AiuniAI/Unique3D что можно использовать?»

## Разделы спеки

Импорт карты глубины; история 8; Тест-шов 1.

## Acceptance criteria

- [ ] Декодер PNG: типы цвета 0/2/4/6, глубина 8 и 16, все 5 фильтров, без чересстрочности (interlace → понятная ошибка).
- [ ] Альфа 0 → фон (минимальная высота); RGB → яркость.
- [ ] Ограничения размера файла и разрешения; повреждённый PNG → локализованная ошибка.
- [ ] Синтетические PNG в тестах (8/16 бит); 16-битный градиент даёт >256 различимых уровней.
- [ ] UI: дропзона/кнопка «Из файла», ошибки через `textContent`.

# 04 — Импорт карты глубины PNG

**Требования:** U01
**Blocked by:** 01, 02
**Status:** ready

## Что должно заработать

Источник «Из файла»: пользователь загружает готовую карту глубины/высот (PNG 8 или 16 бит). Карта декодируется без потери 16-битной точности, приводится к `DepthMap` и масштабируется под картинку; дальше путь общий с нейросетью.

## Из брифа, дословно

> «https://github.com/AiuniAI/Unique3D что можно использовать?»

## Разделы спеки

Импорт карты глубины; история 8; Тест-шов 1.

## Acceptance criteria

- [x] Декодер PNG: типы цвета 0/2/4/6, глубина 8 и 16, все 5 фильтров, без чересстрочности (interlace → понятная ошибка).
- [x] Альфа 0 → фон (минимальная высота); RGB → яркость.
- [x] Ограничения размера файла (64 МБ), стороны (16384) и распакованных данных (256 МБ); повреждённый PNG → локализованная ошибка; данные сверх заявленного размера отвергаются.
- [x] Синтетические PNG в тестах (независимый кодировщик, 8/16 бит); 16-битный градиент сохраняет все 1000 уровней.
- [x] UI: третий источник «Карта глубины из файла (PNG)», кнопка выбора, ошибки через `textContent`; проверено в Chromium (16 бит, ошибки, инверсия, сброс при новой картинке, отмена диалога).

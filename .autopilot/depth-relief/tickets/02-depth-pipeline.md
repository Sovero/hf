# 02 — Рельеф по глубине в пайплайне

**Требования:** R01, R03i, R06i
**Blocked by:** 01
**Status:** ready

## Что должно заработать

Пайплайн принимает внешнее поле рельефа (`reliefField`, 0..1) вместо яркости: слои режутся по глубине, палитра — средний цвет пикселей слоя. Без поля вывод побайтно совпадает с прежним. Источник рельефа и «инвертировать глубину» попадают в `PipelineOptions` и файл проекта; старые проекты открываются как «По яркости».

## Acceptance criteria

- [ ] `mapToLuminanceBands(..., reliefField?)`: порядок слоёв следует полю; палитра — средние цвета слоёв; `luminance` — нормализованное поле.
- [ ] Без `reliefField` результат побайтно равен прежнему (тест на нескольких картинках и режимах).
- [ ] `QuantizeTask.reliefField` проходит через `quantizeOnce`; размер поля проверяется (иначе понятная ошибка).
- [ ] `PipelineOptions`/`project.ts`: `reliefSource`, `invertDepth`; валидация и миграция старых проектов.
- [ ] Потребители, предполагавшие палитру «тёмный → светлый», проверены и не ломаются (слияние ΔE, печатаемость, подбор филаментов).
- [ ] Все 439 прежних тестов проходят.

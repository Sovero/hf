# Разворачивание HueForge Web (deploy)

Готовый пакет `hueforge-web-deploy-v*.zip` — это **собранное приложение**:
не нужны ни `npm install`, ни интернет, ни исходники. Только Node.js.

## Разворачивание на новом ПК

1. Установите [Node.js LTS](https://nodejs.org) (один раз, на весь ПК).
2. Распакуйте `hueforge-web-deploy-v*.zip` в любую папку.
3. Дважды щёлкните **`deploy.bat`** — сервер запустится и откроется браузер на
   `http://127.0.0.1:8080`.

Закройте окно консоли — сервер остановится. Другой порт: `deploy.bat 3000`.

## «Открыть в слайсере» (по желанию)

`deploy-slicer.bat` — то же самое, но с включённой передачей в слайсер:
кнопка **«Открыть в слайсере»** в разделе экспорта отправит собранный 3MF
сразу в установленный слайсер (Bambu Studio / OrcaSlicer / PrusaSlicer).

- По умолчанию функция **выключена** — обычный `deploy.bat` её не включает.
- Сервер слушает только `127.0.0.1`, и запустить чужой exe из запроса нельзя:
  приложение выбирает лишь среди слайсеров, найденных на этом компьютере.
- Слайсер не нашёлся? Укажите путь вручную перед запуском:
  `set HF_SLICER_PATH=C:\Path\To\slicer.exe` (или JSON-массив
  `set HF_SLICER_PATH=["C:\Path\slicer.exe","--flag"]` — аргументы передаются
  перед файлом модели).
- В исходниках то же самое: `set HF_ALLOW_SLICER=1` перед `npm run dev`.

Эквивалент ручного запуска: `node server.mjs 8080 --allow-slicer`.

## Как собрать такой пакет из исходников

```bash
npm run build          # создаёт dist/
npm run pack-deploy    # собирает hueforge-web-deploy-v<версия>.zip
```

`pack-deploy` кладёт в архив только то, что нужно для работы:
`dist/`, `server.mjs`, `slicer-launch.mjs`, `deploy.bat`,
`deploy-slicer.bat` и этот файл.

## Обновление

Распакуйте новый пакет поверх старой папки (или в новую) и снова запустите
`deploy.bat`. Настройки, тема и язык хранятся в браузере и не теряются.

## Для разработчиков

- `npm run serve` — тот же сервер для локальной проверки сборки (`node server.mjs`).
- `install.bat` / `start.bat` из репозитория запускают **dev-версию** (с исходниками
  и `node_modules`) — для доработки. Пакет deploy — для использования.

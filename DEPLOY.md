# Разворачивание HueForge Web (deploy)

Готовый пакет `hueforge-web-deploy-v*.zip` — это **собранное приложение**:
не нужны ни `npm install`, ни интернет, ни исходники. Только Node.js.

## Разворачивание на новом ПК

1. Установите [Node.js LTS](https://nodejs.org) (один раз, на весь ПК).
2. Распакуйте `hueforge-web-deploy-v*.zip` в любую папку.
3. Дважды щёлкните **`deploy.bat`** — сервер запустится и откроется браузер на
   `http://127.0.0.1:8080`.

Закройте окно консоли — сервер остановится. Другой порт: `deploy.bat 3000`.

## «Открыть в слайсере» (по желанию)

`deploy-slicer.bat` — то же самое, но с включённой передачей в слайсер:
кнопка **«Открыть в слайсере»** в разделе экспорта отправит собранный 3MF
сразу в установленный слайсер (Bambu Studio / OrcaSlicer / PrusaSlicer).

- По умолчанию функция **выключена** — обычный `deploy.bat` её не включает.
- Сервер слушает только `127.0.0.1`, и запустить чужой exe из запроса нельзя:
  приложение выбирает лишь среди слайсеров, найденных на этом компьютере.
- Слайсер не нашёлся? Укажите путь вручную перед запуском:
  `set HF_SLICER_PATH=C:\Path\To\slicer.exe` (или JSON-массив
  `set HF_SLICER_PATH=["C:\Path\slicer.exe","--flag"]` — аргументы передаются
  перед файлом модели).
- В исходниках то же самое: `set HF_ALLOW_SLICER=1` перед `npm run dev`.

Эквивалент ручного запуска: `node server.mjs 8080 --allow-slicer`.

## Как собрать такой пакет из исходников

```bash
npm run build          # создаёт dist/
npm run pack-deploy    # собирает hueforge-web-deploy-v<версия>.zip
```

`pack-deploy` кладёт в архив только то, что нужно для работы:
`dist/`, `server.mjs`, `slicer-launch.mjs`, `deploy.bat`,
`deploy-slicer.bat` и этот файл.

## Что нового в этой сборке

Сборка v0.7.7 (с исправлениями после релиза). Главное:

**3D-вьюер**
- Кнопка ортографического вида сверху рядом с «домом» — точная проверка
  площади модели без перспективы.
- Сплошная плита стола под сеткой и мягкая контактная тень под моделью.
- В каталог принтеров добавлен **Qidi Q2 (270×270 мм)** — сейчас 16 моделей
  (Bambu Lab, Prusa, Creality, Anycubic, Sovol, FlashForge, Qidi, Ultimaker).

**Палитра и интерфейс**
- Панель палитры сворачивается до полосы покрытия — меньше прокрутки.
- В строке каждого цвета полные сведения (мм · слои · доля · τ) — при наведении
  показываются целиком, даже когда строка обрезана.
- Кнопки действий переносятся на новые строки, а заголовки панелей сжимаются
  с многоточием — ничего не вылезает за границы даже в узком окне.
- Нативные элементы управления (флажки, поля, ползунки) приведены к теме
  приложения.

**Прочее**
- Автоподбор реальных филаментов из каталога российских производителей,
  квантование по катушкам, список покупок.
- В комплект входит схема архитектуры приложения (`docs/architecture-diagram.html`).

Номер версии виден в шапке приложения (например, «v0.7.7»).

## Чек-лист обновления со старой версии

1. **Остановите старый сервер** — закройте окно консоли, где работает
   `deploy.bat` (или нажмите Ctrl+C в нём).
2. **Скачайте новый пакет** `hueforge-web-deploy-v0.7.7.zip` с GitHub
   (страница релизов) — или возьмите свежую сборку, если вам её передали
   напрямую.
3. **Распакуйте архив поверх старой папки** (или в новую папку — оба
   варианта подходят).
4. **Запустите `deploy.bat`** и дождитесь, пока откроется браузер на
   `http://127.0.0.1:8080`.
5. **Проверьте версию** в шапке приложения — должно быть «v0.7.7».
6. **Проверьте свои настройки**: язык, тема, выбранный принтер и палитра
   хранятся в браузере и сохраняются между обновлениями. Если открылся
   «чистый» вид — вы открыли приложение в другом браузере или профиле;
   настройки привязаны к браузеру, а не к файлам приложения.
7. **Быстрая проверка работы**: загрузите картинку → палитра построится →
   скачайте STL или 3MF → убедитесь, что кнопки панелей не выходят за
   границы.

Если что-то пошло не так, всегда можно вернуться: распакуйте предыдущий
архив и запустите его `deploy.bat` — старые версии пакетов совместимы.

## Для разработчиков

- `npm run serve` — тот же сервер для локальной проверки сборки (`node server.mjs`).
- `install.bat` / `start.bat` из репозитория запускают **dev-версию** (с исходниками
  и `node_modules`) — для доработки. Пакет deploy — для использования.
